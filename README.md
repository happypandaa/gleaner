# 拾闻（Gleaner）

**你的 AI 去收集，你在这里看。**

拾闻是熊猫小抽屉的本机资讯简报应用。你用自己的话写下关注主题，由自己的 AI 工具收集和整理内容；拾闻保存历史，提供阅读、收藏、备注和反馈界面，供 AI 下次更新时参考。

## 打开拾闻

1. 在熊猫小抽屉选择「添加应用 → 本机文件夹」，选中这个包含 `panda.json` 的文件夹。
2. 打开拾闻。首次打开会创建本机数据库，无需安装依赖、构建或填写 API Key。
3. 点左下角「在 AI 里使用拾闻」，复制「开始使用」那句话，发给自己常用的 AI 工具。
4. 在 AI 里用自己的话说清想关注什么。AI 会把主题整理好给你确认，确认后马上更新第一期。
5. 回到拾闻刷新，查看第一期。之后可以在「主题」页调整设置，或继续在 AI 里说。

拾闻无法知道你是否已经把这句话发给了 AI。发过、设置好的不用再发；换了 AI 工具或对话丢失时，再发一次即可，AI 会按已有主题继续。

界面需要熊猫小抽屉提供的 SDK，直接用浏览器打开 `app/index.html` 不能读写数据。请使用已支持 agent 应用和应用路径接口的熊猫小抽屉版本。

## 日常使用

| 页面 | 用途 |
| --- | --- |
| 今日 | 阅读最近一期内容和今日要点，收藏、忽略、写备注，留下深入了解或找类似内容的请求 |
| 全部 | 搜索历史，按日期、主题和状态筛选 |
| 收藏 | 集中查看收藏，搜索备注 |
| 主题 | 查看和调整 AI 按你的描述建立的主题：关注点、来源、排除内容、每次条数和额外记录；查看 AI 学到的偏好。新增主题请告诉 AI |
| 记录 | 查看 AI 每次更新的结果和说明 |

每页都可手动刷新，窗口重新获得焦点或页面重新可见时也会刷新。用户正在编辑的内容不会因自动刷新被覆盖。AI 请求会留到下次更新处理，结果显示在对应内容下方。

想立即更新时，对 AI 说“更新简报”，或从「在 AI 里使用拾闻」复制提示词。拾闻本身不调起 AI、不读取 AI 会话、不调用 AI 接口，也不负责定时调度。

想每天自动更新，可以在「记录」页点「想让 AI 每天自动更新？」，把提示词发给 AI，由 AI 工具创建定时任务。拾闻的数据在本机，所以到点时电脑需要开着、没有睡眠，AI 工具的应用也要在运行；错过时间后，有的工具会在开机后补一次，有的会跳过。

## 文件和数据

```text
panda.json             熊猫小抽屉应用清单
AGENTS.md              AI 日常更新与写入规则
app/                   HTML、CSS、原生 ES 模块，无构建步骤
docs/design.md         产品与实现约定
docs/database.md       数据表、字段与写入分工
docs/views.md          扩展主题展示方式
docs/design/           静态界面草图
data/main.sqlite       本机数据库（首次打开后创建，不进 Git）
data/attachments/      本机配图缩略图（不进 Git）
```

数据库是唯一的长期存储，不使用中间 JSON 文件。主题、内容、反馈、请求、偏好与运行记录都保存在本机。AI 不在线时，阅读和反馈仍可使用。删除主题会保留历史内容；删除应用时，文件夹和数据是否保留以熊猫小抽屉登记的目录归属为准。如果曾设置外部定时任务，请同时在 AI 工具里关闭。

AI 开始时单独记录运行状态，在事务外完成搜索、请求处理、下载和缩图，再以一个短事务提交结果，避免影响同时使用的界面。AI 只新增内容，不覆盖用户收藏、忽略和备注。详细约束见 `AGENTS.md` 和 `docs/database.md`。

## 修改和扩展

用户可用熊猫小抽屉的「按你的想法改」让 AI 调整界面。改代码前关闭拾闻窗口，完成后重新打开即可生效。主题的「额外记录」通常无需改程序；需要对比表等特殊展示时，按 `docs/views.md` 新增并登记展示方式。首版不内置车价对比表。

本应用不引入前端框架或构建工具。若开发检查确需 Node.js 依赖，使用 pnpm。代码版本不包含 `data/`；Git 不能代替数据备份。验收结果和仍待实测的能力以实施报告为准，复制提示词或模拟接口测试不能证明外部 AI 定时任务已经成功。

使用带 `node:sqlite` 的 Node.js 可运行数据保护检查：

```sh
node --test --test-concurrency=1 tests/db.test.mjs
```

测试使用独立的内存数据库，覆盖初始化回滚、版本 1 到 2 的升级、主题修改冲突保护、重复内容保留反馈、删除主题保留历史、筛选分页、请求去重和旧配图清理，不会打开 `data/main.sqlite`。

本机实施及验证记录见 [实施报告](docs/implementation.md)。若添加时提示 `agent` 是未知字段，说明正在运行的平台包还没有包含 agent 应用支持；需要重新构建并打开新版熊猫小抽屉。
