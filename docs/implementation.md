## 已实现

- 原生 HTML、CSS、ES 模块的静态网页应用，无第三方运行依赖、构建步骤、后端或 AI 接口；启用熊猫小抽屉 SDK，并声明 agent 运行规则。
- 数据库启动时以一个原子事务初始化六张表、索引、约束和 `schema_version = 1`；已存在的数据不重置，未来版本拒绝降级打开。
- 首次引导：创建主题或使用示例，复制含真实应用路径及时间的设置提示词，等待成功的 `setup` 记录，再进入第一期。复制动作不会伪造连接或定时成功。
- 今日：最近一期成功或部分成功运行、未更新提示、要点、搜索、主题及未读筛选、分组列表和阅读面板、额外信息、已读、收藏、忽略原因及撤销、备注失焦保存。
- 全部：标题、摘要、备注搜索；今天、7 天、30 天及自定义日期；14 天内容量日期条；主题与状态筛选、可移除条件、时间排序。每次查询最多 50 条，按需加载。
- 收藏：卡片和列表、主题和备注筛选、标题及备注搜索、收藏时间或发布时间排序。
- 主题：完整编辑、开启及暂停、顺序、额外记录和展示方式；显示统计和学到的偏好，支持删除偏好。删除主题需确认，历史内容及其收藏备注保留。
- 更新与记录：上次状态、定时安排、配图说明、设置与手动提示词、路径复制、时间选择、30 条一批的运行记录、内容格式异常提示。
- 深入了解及找类似的请求：记录为待处理，同一内容和类型的待处理请求去重；外部 AI 写回结果后可刷新显示。
- 每页手动刷新，窗口获得焦点及页面重新可见时刷新；不会因刷新覆盖主题草稿或备注。读取失败保留原页面并提供重试；图片按本地、HTTPS 原图、来源首字回退。
- `app/views/` 登记独立展示方式，未知方式回退列表；首版没有内置车价对比表。扩展说明见 `docs/views.md`。
- 后台每批最多 50 条检查超过 180 天的未收藏配图，仅处理规定目录的哈希缩略图；保留文字反馈、收藏及共享图片，删除失败恢复引用。收藏在数据库认领清理前保存时会优先保留。

## 与设计的细节差异

- `learned.topic_id` 使用删除主题时级联删除该主题偏好，避免这些偏好在主题删除后被误当成全局偏好；历史内容仍按设计保留。
- 额外信息的 JSON 语法由数据库约束；对象形状及字符串值在查询时验证，无效内容被跳过并计数。主题关键词由程序保存为字符串数组。
- 首次引导完成状态由已保存主题与成功 `setup` 记录推断；当前会话在检测到首次成功后保留第三步按钮，重新打开已有简报时直接进入今日。不增加浏览器长期存储。
- 旧配图清理只接受文档规定的哈希路径，其他路径跳过，避免清理未知文件。
